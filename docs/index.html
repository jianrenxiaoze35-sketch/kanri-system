旧・レジ締め・売上集計アプリからのデータ移行

統合前にお使いだった単体版「レジ締め・売上集計アプリ」に残っているデータを、このページに一度だけ取り込むことができます。手順：①旧アプリを開く　②「設定」タブの「全データをバックアップ(JSON)」でファイルを保存　③下記でそのファイルを選択し「移行する」を押す。日付ごとのレジ締め・売上集計データ、提出履歴、Squareアーカイブ、基本設定を取り込みます。同じ日付のデータが既にある場合は上書きされます。旧アプリの商品データベースは、商品コードが一致するものは商品マスタのPOS関連項目（POSシステム・税率・会計区分・価格区分）のみ更新し、一致しないものは新規商品として商品マスタに追加します（原価・仕入れ関連の項目は空のまま追加されるため、必要に応じて商品マスタで補ってください）。
